A make.fun bounty entry: one funny line, under 200 characters, that a
hopeless tech support agent says to a desperate customer.

> I restarted your router — if it still won't connect, your Wi-Fi has filed for divorce and taken the password with it.

(117 characters.)

## The bounty

[Have You Tried Turning It Off?](https://make.fun/bounty/u-motasimfuad-have-you-tried-turning-it-off-154a938b)
on [make.fun](https://make.fun/?ref=jwvw22pf) — $10 in USDC. An AI judge
compares the lines two at a time over three private blind rounds, and the
best ranked lines share the reward pool.

## Run it

```sh
python3 main.py
```

Prints the line to stdout and writes it to
`$MAKEFUN_OUTPUT_DIR/entry.txt`. Python standard library only,
deterministic, exit 0.
